# Celeste Wave: Starfish Drift

Um protótipo de jogo em browser em HTML5 Canvas inspirado na fusão de:
- Kibo Wave
- Celeste / Madeline
- Starfish Room

## Como rodar

1. Abra o arquivo `index.html` em um navegador, ou
2. Rode um servidor local simples:

```bash
python3 -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000/
```

## Controles

- A / D: mover
- W / ↑: pular
- Shift: dash
- R: reiniciar

## Objetivo

Reúna os 5 fragmentos e ative a porta final.

## Observação

Este é um protótipo de fusão visual e mecânica, criado como base para continuar refinando o jogo com os assets e regras dos arquivos originais, quando eles forem disponibilizados.
